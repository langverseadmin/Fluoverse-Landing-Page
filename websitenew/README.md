# Fluoverse - Premium Landing Page

A modern, clean, and minimal website built for high conversion rates. Features a premium dark theme with smooth animations and micro-interactions.

## Features

- **Premium Dark Theme**: Modern, sophisticated dark design that feels premium
- **High Converting**: Optimized layout with testimonials, social proof, and clear CTAs
- **Fully Responsive**: Looks great on all devices from mobile to desktop
- **Interactive Demo**: Engaging demo section with animated dashboard preview
- **Smooth Animations**: Subtle animations and micro-interactions throughout
- **Modern Tech Stack**: Built with HTML5, CSS3, and vanilla JavaScript
- **Performance Focused**: Optimized for fast loading and smooth interactions

## Pages

1. **Homepage** (`index.html`)
   - Hero section with compelling value proposition
   - Features showcase
   - Interactive demo section
   - Testimonials for social proof
   - Clear call-to-action

2. **Pricing** (`pricing.html`)
   - Three-tier pricing structure
   - Monthly/yearly billing toggle
   - Feature comparison table
   - FAQ section
   - Conversion-optimized layout
